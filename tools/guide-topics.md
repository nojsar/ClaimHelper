# Guide topic queue

Prioritized backlog for the weekly auto-published appeal guide
(`web/appeals/`). The scheduled task takes the TOP topic, writes the guide,
and deletes the line. Add new ideas at whatever priority fits — real search
intent from people who just got a denial letter beats clever keywords.

Each line: `slug | working title | angle notes`

**Extra rules for STATE-SPECIFIC guides:** only name the regulator and
external-review program given in the angle notes (they are verified) — do
not invent statutes, deadlines, or fee amounts; state timeframes generally
("typically about four months — confirm with the regulator") unless the
notes give them. EVERY state guide must include the self-funded ERISA
carve-out: employer self-funded plans are exempt from state external review
and use the federal process instead (link to the self-funded-erisa-appeal
guide once it exists, and /appeals/external-review meanwhile). Target search:
"appeal health insurance denial <state>".
